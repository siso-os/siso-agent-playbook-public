SISO Agent Playbook / System Map

A fleet that can explain, constrain, and test itself.

This repository is an operating layer around model workers. It turns available model lanes into bounded jobs, gates them with governance, observes them mechanically, and tests the operating doctrine for drift.

The control loop

A coordinator checks health, chooses a measured lane, starts one fresh worker with one prompt-bank brief, and waits on a file or process event. The worker exits. Telemetry records the outcome. Scheduled checks make broken assumptions visible before the next large wave.

beforeRead $WORKSPACE/.agents/telemetry/LANE-HEALTH.json.
duringRun a bounded command with a named result path and timeout.
afterCapture PASS, FAIL, or BLOCKED plus evidence; then terminate the worker.

The installation boundary

install.sh projects this repository into a user’s machine: skills become symlinks, tools become executable copies, telemetry gets a workspace home, and launchd gets generated path-aware schedules. uninstall.sh uses the install manifest to remove owned files and restore collisions.

The Five Laws

Doctrine expressed as mechanics

These are the stable rules. Individual models, prompts, and tools may change; the laws define what replacements must preserve.

One agent, one task

Start with fresh context. Do not reuse an accumulating session as a worker queue.

Completion is an event

Wait on files, process status, or explicit verdicts. Never spend model turns polling a terminal.

Budgets are infrastructure

Put limits in the gateway and probes in the heartbeat. Discipline alone is not a control plane.

Route by evidence

Use benchmark strengths as the prior and local task outcomes as the posterior.

Test the doctrine

Encode rules in scripts, gates, schedules, and invariant checks because prose decays.

Operate It

The stranger’s runbook

Install

Project the repo

Run WORKSPACE="$HOME/SISO_Workspace" ./install.sh, set the Bifrost key in the generated secrets file, and ensure ~/bin is on PATH.

Dispatch

Check, brief, run

Confirm a lane is UP, select a prompt, name the result path and timeout, then use the smallest dispatch tool that fits the job.

Verify

Trust artifacts

Read the worker verdict and evidence, inspect telemetry, and use stack-check whenever the stack changes or the weekly schedule reports drift.
